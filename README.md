# 🤖 Telegram AI Automation Using n8n

An AI-powered Telegram automation workflow built using **n8n, Telegram Bot API, and OpenAI** to process user messages and generate intelligent responses.

## 🚀 Project Overview

This project demonstrates how to integrate Telegram with an AI model through n8n for automated conversational interactions.

## ✨ Key Features

- Telegram Bot API integration
- Automated message handling
- AI-powered response generation
- Workflow orchestration using n8n
- Real-time conversational automation

## 🔄 Workflow Architecture

Telegram Message → n8n Telegram Trigger → OpenAI Model → Process Response → Telegram Reply

## 🛠️ Tech Stack

- n8n
- Telegram Bot API
- OpenAI API
- JSON

## ⚙️ Setup Instructions

1. Create a Telegram bot using BotFather.
2. Configure Telegram credentials in n8n.
3. Import the workflow JSON.
4. Configure OpenAI credentials.
5. Activate the workflow.
6. Send a message to the Telegram bot to test.

## 🎯 Learning Outcomes

- API integration with n8n
- Telegram bot automation
- AI model integration
- Event-driven workflow development

## 🔐 Security

Never commit Telegram bot tokens, OpenAI API keys, or other credentials to GitHub.
